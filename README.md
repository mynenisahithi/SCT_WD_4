# todo
A To-Do List Web Application built using HTML, CSS, and JavaScript. The application allows users to add, edit, complete, delete tasks with date and time management functionality.  This project demonstrates frontend web development concepts such as DOM manipulation, event handling, task management logic, and interactive UI design using JavaScript.
